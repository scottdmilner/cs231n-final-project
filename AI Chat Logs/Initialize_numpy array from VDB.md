The primary issue with your code is that **`vdb.readAllGridMetadata()` only reads the metadata and transforms from the VDB file, not the actual voxel data**\ue200\ue202turn1search2\ue202turn1search0\ue201. This means the grid objects returned don't contain the volume data needed to copy into your numpy array.

## The Problem

When you use `readAllGridMetadata()`, you're getting grid objects that only have metadata information (name, grid class, dimensions, etc.) but no actual voxel values. That's why calling `copyToArray()` on these grids doesn't populate your numpy array with data - there's no data to copy.

## The Solution

Use `vdb.read()` or `vdb.readAll()` instead to load the actual grid data\ue202turn0search0:

```python
import openvdb as vdb
import numpy as np

volume_size = (100, 100, 100)
volume_data = np.zeros(volume_size, dtype=np.float32)

# Use read() or readAll() to load actual voxel data
grids = vdb.readAll("data/smoke_lowres/smoke_lowres.80.vdb")

for grid in grids:
    if grid.name == "density":
        print(grid.info())
        grid.copyToArray(volume_data, ijk=(0,0,0))

# check if any data has been copied over
print(volume_data.sum())
```

## Key Differences

- **`readAllGridMetadata()`**: Reads only metadata and transforms (fast, minimal memory)
- **`readAll()`**: Reads complete grids including all voxel data (slower, more memory)
- **`read()`**: Reads specific grids by name

The metadata-only function is useful when you only need to inspect grid properties without loading large volumes into memory, but for operations like `copyToArray()`, you need the full grid data\ue200\ue202turn1search1\ue202turn0search0\ue201.
